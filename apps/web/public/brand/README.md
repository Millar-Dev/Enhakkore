# Enhakkore brand asset library

- `originals/` — the original Enhakkore and WSC logo files, untouched master references
  (the same files the site uses from `/partners/`). Never edit or overwrite these.
- `refined/` — prepared versions made from the originals by cropping, resizing and
  placing on a background. The artwork itself is not redrawn or recoloured.
  - `enhakkore-logo-full.png` / `@2x` — transparent full logo
  - `enhakkore-nav.png` (96 px high), `enhakkore-footer.png` (208 px high)
  - `enhakkore-emblem.png` — the E, globe and aeroplane without the wordmark
  - `enhakkore-square-1080.png`, `enhakkore-emblem-square-512.png` — social / profile
  - `enhakkore-on-dark-plate.png` — for dark backgrounds (cream plate; navy artwork stays navy)
  - `enhakkore-icon-32/180/192/512.png`, `favicon-32.png`, `favicon.ico` — icons
  - `wsc-logo.png` / `@2x`, `wsc-square-1080.png`, `wsc-on-dark-plate.png`
- `colours.json` — colours sampled from the original artwork: navy ≈ #000c24–#0c1830,
  gold ≈ #cb993a; WSC blue ≈ #000c6c. The site's navy/gold tokens follow these.

No SVG is included: an exact vector would have to be redrawn by a designer from the
original artwork, and the brief forbids unapproved reconstructions. Photos, videos and
other media are managed in the control centre → Media library.
